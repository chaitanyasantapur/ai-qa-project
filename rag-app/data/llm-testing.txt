Testing LLM applications is different because outputs are not deterministic. A RAG system should be evaluated on retrieval quality and answer quality separately. Faithfulness measures whether the answer is supported by the retrieved context. Hallucination is when the model states facts that are not in the context. A golden dataset is a fixed set of questions with expected answers used to catch regressions when prompts or models change. LLM-as-judge uses a second model to score answers, and should be validated against human judgement.
